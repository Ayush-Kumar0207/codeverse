# Getting Help with CodeVerse

Choose the channel that matches the situation so questions remain useful to the next person.

| Need | Where to go |
| --- | --- |
| Setup or usage question | [GitHub Discussions](https://github.com/Ayush-Kumar0207/codeverse/discussions) |
| Reproducible defect | [Bug report](https://github.com/Ayush-Kumar0207/codeverse/issues/new?template=bug_report.yml) |
| Product or contributor idea | [Ideas discussion](https://github.com/Ayush-Kumar0207/codeverse/discussions/new?category=ideas) |
| Documentation problem | [Documentation issue](https://github.com/Ayush-Kumar0207/codeverse/issues/new?template=documentation.yml) |
| Security vulnerability | [Private vulnerability report](https://github.com/Ayush-Kumar0207/codeverse/security/advisories/new) |
| Production availability | [Public status page](https://codeverse-rho.vercel.app/status) |

## Before asking

Search existing issues and discussions, try the latest `main`, and include the smallest reproduction you can. Remove tokens, credentials, private source code, personal data, and unrelated logs.

This is a community-maintained project, so response times are best effort. A precise report with a minimal example is usually the fastest route to a useful answer.
